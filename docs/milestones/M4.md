Verdict: the runtime and content half of the loop is ready. The editor half (FR-EDT-020/030/050/100 and the A4
run-in-player button) belongs to the M2/M3 editor scope that never landed, and it blocks "editor gizmo polish" and
"autosave" from this milestone's list. It needs its own editor catch-up milestone before the UC-C loop can be
rehearsed for real.

## Open

1. **Windows / MSVC.** Nothing in M4 was built with MSVC: the CI container is Linux-only. Three pieces wait for a
   Windows build: the `mce_engine.dll` export ledger (MCE_API decorations + explicit instantiations, finding F33,
   today the umbrella is Linux-only and Windows links the game statically), the `.rc` icon/VERSIONINFO resource from
   `mce_ship_metadata`, and the "double-clicked on a clean Windows 10 VM by a non-programmer" gate.
2. **Artifact A art.** Kenney's 2D packs live on kenney.nl, which this environment cannot reach (only GitHub is
   reachable). Artifact A therefore ships Kenney CC0 sound effects from the 3D Platformer starter kit, while its
   sprites, tiles, win jingle and music are still the generated set from M3.
3. **Editor catch-up** (see the UC-C rehearsal above): scene document + save/load + autosave, inspector, entity
   CRUD, translate gizmo + picking, run-in-player.
4. **LRN gates 1–5 written from memory** are the author's own deliverable, not something an agent can close.
