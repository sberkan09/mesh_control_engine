# M-LAYOUTTOOLS — layout commands for the editor and the MCP tools (milestone record)

**Status:** done 2026-11-20 (steps 1 to 4). **Owner: the "Geliştirme rutini 3" thread.** The editor has align, distribute, snap, flip, match and duplicate-offset commands, but a person or an agent can only reach them from the editor shell; the MCP server has none, and there is no way to repeat a group into a grid. This milestone adds the grid copy and exposes the layout commands as MCP tools, so a scene for a game sample can be laid out headless.

|---|---|---|
| 1 | `array_duplicate` in editor core: copy the selection into a columns x rows grid, one undo entry, refuses bad input and more than 4096 copies | done 2026-11-20: `array_duplicate.h/.cpp`, `test_array_duplicate.cpp` (grid positions, one undo entry, parent and child, refusals, limit, 200-seed fuzz against a model) |
