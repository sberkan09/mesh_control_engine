# M6 — 2D extras (milestone record)

**Scope:** the 2D-extras part of ROADMAP M6 (particles through the sprite batch, parallax layers, lit-2D sprites +
2D post). Design decisions: ADR-0031. **Measured on:** the Linux CI container (4 cores), `scripts/ci/local_ci.sh`.

| ROADMAP M6 item | Where | Evidence |
|---|---|---|
| Particles through the sprite batch (FR-R2D-070) | `.mcpart` → `CHNK_PART` (`particle_importer.cpp`, `ParticlePresetChunk`); `kit::ParticleEmitter`, `kit::ParticleSystem`, `install_particles` (`mce/kit/particles.h`); drawn by `SpriteExtract`; installed by `mce_player` and play-in-editor (ADR-0031 §1) | `test_kit`: burst/rate/duration/cap counts, lifetime retirement, integration against the hand-computed position, deterministic hash per seed, bursts on demand, one-shots destroy themselves, the hierarchy-placed emitter, 2,000 particles in one additive MDI group and culled off-screen, `.mcpart` → cooked scene → emitting, cook errors name the key |
| Parallax layers (FR-R2D-050) | `kit::Parallax` (`components.h`) applied by `SpriteExtract`; tilemap draw-time offset (`SpriteBatch::add_tilemap`, `Renderer::record_2d`) (ADR-0031 §2) | `test_kit_gl`: three layers at factors 0.25 / 0.5 / 1 land at the expected pixels as the camera moves, per-axis factors, `repeat_x` covers the view at any camera position with only the copies it needs; `test_render_gl`: an offset tilemap draws shifted and culls by its shifted bounds |
| Lit-2D sprites (FR-R2D-090) | `SpriteSetDesc::lit`/`normal_key`, `Lights2D` on the batch, `LightsU` + normal array in the sprite shader (`renderer.cpp`), orientation bits (`pack_orientation`); kit `Sprite::normal_map` + `Light2D` collected by `SpriteExtract` (ADR-0031 §3) | `test_render_gl`: default lights leave a lit sprite unchanged, a colored point light shades the lit sprite only, out-of-radius stays at ambient, a tilted normal is lit from its side and swaps sides when rotated half a turn or flipped; `test_kit_gl`: a cooked normal map + Light2D entities (ambient summed, off-view light culled) light a kit sprite; `test_render`: orientation packing |
