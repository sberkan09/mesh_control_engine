# docs/design/

Game design documents for the games made with the engine: story, flow, gameplay, visual and audio
direction, the technical plan, and the engine gaps each game exposes. A design document is written
before its game and updated as the game lands (its last section is the gap log).

| Document | Game | Project | Purpose |
|---|---|---|---|
| [solstice-reach.md](solstice-reach.md) | Solstice Reach | `projects/SolsticeReach` | the 3D graphics showcase: one island under eight lighting regimes |
| [undelivered.md](undelivered.md) | Undelivered | `projects/Undelivered` | the light novel: seven letters, six days, five endings |

Earlier games (Ember Step, Ashen Court, Kindle, Prism Break, Undertow) are documented in their
milestone and research records (`docs/milestones/`, `docs/research/`).
