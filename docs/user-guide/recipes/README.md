# Recipes

Short, complete walkthroughs for one job each, written for an agent driving the MCP server (chapter
14) and just as usable by hand. Each lists the tools in the order to call them.

| Recipe | What you end with |
|---|---|
| [A level that a bot can finish](level-a-bot-can-finish.md) | a saved level, a `walk_to` playtest that finishes, a `.mctest` that keeps it that way |
| [Screens that stay right](screens-that-stay-right.md) | goldens of the title and each level, checked by `image_diff` after every change |
| [A new component, live](new-component-live.md) | a component and a system in the game module, built and reloaded into the running server |
