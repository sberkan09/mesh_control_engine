# Undelivered

The engine's narrative showcase: a light novel on the 2D kit. Kuzgun Island, 1994, the last week
of the ferry. Deniz, nineteen, comes back to pack up the post office their grandmother ran for
forty years and finds, in a locked drawer, seven letters she never delivered. Six are for people
still on the island. One is for Deniz. Seven days, six deliveries, five endings, about forty
minutes a run. Design: [docs/design/undelivered.md](../../docs/design/undelivered.md).

It runs on the engine's visual-novel kit (`mce_kit_novel`, `mce/kit/novel.h`; user guide chapter 21)
and its script compiler (`mce story compile`). What is the project's own: the script
(`story/*.story`, 14,700 words, with its id tables in `story/story.json`), the drawer, the night
journal and the HUD line (`games/undelivered/module/undelivered.cpp`), the paper cut-out art and
the sound (`tools/gen_assets.py`),
the scene (authored through the editor MCP server by `tools/author_scene_mcp.py`). The fonts are
OFL (CREDITS.md).

## Play

Inside the engine tree:

    cmake --preset linux-gcc-debug
    cmake --build --preset linux-gcc-debug --target undelivered
    build/linux-gcc-debug/projects/Undelivered/undelivered

With the installed SDK (user guide chapter 1): `mce example Undelivered` copies it out, then
`mce build Undelivered`, `mce play Undelivered`,
`mce editor Undelivered`, `mce mcp Undelivered`, `mce ship Undelivered --version 1.0`.

The stock player's default input map (the game adds no keys of its own):

| Action | Keys | Gamepad |
|---|---|---|
| Advance a page, confirm | Enter, Space, J, left mouse | A, X |
| Choose, move between envelopes | arrows / WASD | d-pad, left stick |
| Skip read text | hold J or left mouse | hold X |
| Backlog (open / scroll / close) | mouse wheel up, then up and down; wheel down or Enter closes | - |
| Leave the drawer shut today | mouse wheel down on the drawer screen | - |
| Pause, quit | Esc (the player's overlay), then Q | Start |

Saves: the game writes `undelivered_autosave` at every night journal and the player writes it
again on a clean quit; *Continue* on the title picks it up. `-save <name>` plays another slot,
`-newgame` is the title's *New game*. The kit's flags: `-novel.autoplay N` (the bot plays by
tag: 1 first, 2 leave, 3 stay, 4 shut, 5 write), `-novel.label <label> [-novel.skip N]` (start at
a script label), `-novel.instant 1` (no typewriter). Useful flags: `-headless 1 -ticks N` (no window; prints
`N ticks, E entities, state_hash H`), `-frames N -capture shot.ppm` (quit after N frames and write
the last one).

## Layout

| Path | What |
|---|---|
| `Undelivered.mceproj` | project identity: name, engine version, games, start scene |
| `story/*.story` | the script: Day 1, the day loop (mornings, the drawer, afternoons, nights), the seven letters and six deliveries, the afternoons, Day 7 and the endings; `story/REPORT.md` is the compiler's word count |
| `story/story.json` | the script's manifest: characters and cast, expressions, locations and their times of day, music, sound, endings, option tags and the bot's preferences, flags and counters, the `@drawer` command, fonts for pagination |
| `tools/gen_assets.py` | regenerates `assets/textures` and `assets/audio` (deterministic; about a minute) |
| `tools/author_scene_mcp.py` | re-authors `assets/scenes/main.mcscene` through `undelivered_mcp` (`--mcp build/.../undelivered_mcp`) |
| `assets/scenes/main.mcscene` | the stage: 79 entities, the kit's `StagePart` (paper layers, cast slots, box, rows, letter card, panel, lights, sound beds, the camera), the game's `DrawerPart` (envelopes, stamps) and the `StoryState` save carrier |
| `games/undelivered/module/` | `components.h` (`DrawerPart`), `undelivered.cpp` (the kit's hooks: the drawer, the journal, the HUD, the Letters page), `story_data.h` (generated by `mce story compile`) |
| `games/undelivered/host/main.cpp` | the stock player with this game's module and pack, the kit's `novel.*` flags; adds `-save undelivered_autosave` to windowed runs |
| `tests/test_undelivered.cpp` | the script tables, the authored scene, a player's inputs, the five bot policies to their endings, a save reloaded mid-run, determinism |

## How it is built

- The script is data. `mce story compile .` (`tools/story/story_compile.py` in the engine tree)
  turns `story/*.story` (a small line-oriented format: `@scene`, `Speaker(expr): text`,
  `> "option" [condition] {tag} -> label`, `@if`, `@set`, `@letter`, `@journal`, `@ending`, and
  the game's own `@drawer`) and `story/story.json` into one `mce::novel::Program`: an `Op` table,
  a string table and an option table, pre-wrapped into pages of four lines of at most 62 bytes,
  because `TextLabel.text` is a `FixedString<64>` and the runtime never measures text.
- The kit's VM runs that program over one `StoryState` component: the flags (32 named ones,
  delivered and read per letter), the counters (trust per character, resolve, the day...), the
  program counter and the call stack, and the picture (location, hour, LUT, music, cast slots).
  Every field carries the `Save` flag, so the engine's save game *is* the run: the autosave at the
  journal, the player's `-save` load at start, *Continue* on the title.
- The kit's stage writes into the scene's `StagePart` entities each tick: the five paper layers of
  the location (lit sprites with one shared paper normal map, an ambient light and a lamp that move
  with the hour, from `story.json` "times"), the cast with a speaking-character lift and the others
  dimmed, the typewriter on the four lines, choice rows with gated options greyed, the letter card
  in the handwriting font, the panel for the journal, the backlog, the ending card and the title's
  *Letters* page, the LUT on the camera's `Post2DComponent`, and the two looping `AudioSource`s
  whose clips it swaps. The game's hooks add the drawer screen (envelopes, stamps, the three
  actions), the journal's lines and the HUD.
- The bot (`NovelState::autopilot`) plays whole runs by option tag (`first`, `leave`, `stay`,
  `shut`, `write`), which is how the test reaches all five endings headless, in a few seconds.
