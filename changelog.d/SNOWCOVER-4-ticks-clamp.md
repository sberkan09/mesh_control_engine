- Weather and SnowCover durations no longer divide by zero (M-SNOWCOVER, SNOWCOVER-4): `transition_seconds`, `dry_seconds`, `auto_change_seconds` and `SnowCover.build_seconds` / `melt_seconds` set to `+Inf` or a huge value (`FLT_MAX`) are clamped to 2^31 ticks instead of overflowing `llround` and wrapping a denominator to 0 (SIGFPE while it snowed). Values in range, and 0 / NaN / negative (one tick), behave as before, so state hashes do not change.
