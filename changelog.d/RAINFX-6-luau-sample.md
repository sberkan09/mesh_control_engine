- Luau rain effects and the weather sample ripples and splashes, M-RAINFX step 7d (milestone closed): `weather.ripples_strength()`, `ripples_density()`, `ripples_speed()` and `ripples_ring_width()` read the first `RainRipples` (`mce/kit/rain_ripples.h`) and `weather.set_ripples{strength=, density=, speed=, ring_width=}` writes them; `weather.splash_rate()`, `splash_height()`, `splash_life()`, `splash_radius()` and `splash_seed()` read the first `RainSplash` (`mce/kit/rain_splash.h`) and `weather.set_splash{rate=, height=, life=, radius=, seed=}` writes them; `weather.thunder_speed()` and `thunder_volume()` read the first `ThunderDelay` (`mce/kit/thunder_delay.h`) and `weather.set_thunder{speed=, volume=}` writes them. Every key is optional and values are clamped to the component's Range; an unknown key (the engine-written `counter`, `pending` and the clip included), a non-number (NaN included) or a scene without the component (or a world without weather) raise a named Luau error and write nothing. Typed in `mce.d.luau`. Sample `samples/12_weather`: the Weather entity carries a `RainRipples` and a `ThunderDelay` (no clip: the sample has no sfx asset, so no thunder sounds), and a new `Splash` entity carries a `RainSplash` on a `ParticleEmitter3D` (entity count 11 to 12); the headless test pins the entity count and the script logs `rain fx:` every 150 ticks. The scene's state hash changes (new components and entity, 600 ticks ecb6635fa5c95956, 2700 ticks 822f500a69651bee); `RainRipples`, `ThunderDelay` and `RainSplash` leave `sample_coverage.allow`.
