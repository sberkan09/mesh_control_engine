- Snow cover in the kit, M-SNOWCOVER step 6c: new `SnowCover` component (`mce/kit/snow_cover.h`, one per scene: `strength`, `build_seconds`, `melt_seconds`, `coverage`, `noise_scale_m`, `wind_bias`, and the engine-written saved `snow_q`/`cover`), registered by `install_weather` with the system `kit_snow_cover` (after `kit_weather`), which grows the cover in integers while `Weather.current` is snow and melts it afterwards. `Kit3DExtract` hands the scene `cover * strength` (through `apply_quality`) only when it has both a `Weather` and a `SnowCover`; every other scene stays bare and its state hash is unchanged (`Weather` is untouched).
