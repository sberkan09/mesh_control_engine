- Luau `weather` wind sway, M-WINDSWAY step 2: thin over the first `WindSway` (`mce/kit/wind_sway.h`). `weather.sway_amplitude()`, `weather.sway_frequency()`, `weather.sway_gust()` and `weather.sway_flutter()` read the four gains; `weather.set_sway{amplitude=, frequency=, gust=, flutter=}` writes any of them (every key optional, values clamped to the component's Range). An unknown key, a non-number (NaN included) or a scene without a `WindSway` (or a world without weather) raise a named Luau error and write nothing. Typed in `mce.d.luau`; user guide 27.3.
