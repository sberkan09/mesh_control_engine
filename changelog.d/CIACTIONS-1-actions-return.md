- CI: GitHub Actions is back now that the repository is public (standard hosted runners are free there). `.github/workflows/ci.yml` runs `scripts/ci/local_ci.sh --task` on PRs into `master`; `.github/workflows/integration.yml` runs the full matrix on `master` on a schedule, caches ccache with `actions/cache`, and pushes `ci/regen-<sha>` for stale generated files. `scripts/ci/local_ci.sh` stays and remains the gate until the Actions runs are proven green.
