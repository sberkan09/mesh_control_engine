- Luau `weather` wet surfaces, M-WETSURFACE step 5d: thin over the first `WetSurfaces` (`mce/kit/wet_surfaces.h`). `weather.wet_strength()`, `weather.wet_darken()`, `weather.wet_puddles()` and `weather.wet_puddle_scale()` read the fields; `weather.set_wet{strength=, darken=, puddles=, puddle_scale=}` writes any of them (every key optional, values clamped to the component's Range). An unknown key, a non-number or a scene without a `WetSurfaces` raise a named Luau error and write nothing. Typed in `mce.d.luau`; user guide 27.3.
