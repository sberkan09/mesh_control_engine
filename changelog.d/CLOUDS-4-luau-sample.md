- Luau clouds and the weather sample's cloud layer, M-CLOUDS step 9d (milestone closed): `weather.cloud_strength()`, `weather.cloud_fair_coverage()`, `weather.cloud_overcast_coverage()`, `weather.cloud_scale()`, `weather.cloud_speed_scale()` and `weather.cloud_height()` read the first `CloudLayer` (`mce/kit/cloud_layer.h`) and `weather.set_clouds{strength=, fair_coverage=, overcast_coverage=, scale=, speed_scale=, height=}` writes it. Every key is optional and values are clamped to the component's Range; an unknown key, a non-number (NaN included) or a scene without the component (or a world without weather) raise a named Luau error and write nothing. Typed in `mce.d.luau`. Sample `samples/12_weather`: the Weather entity carries a `CloudLayer` (the defaults) and the script logs `clouds:` every 150 ticks (entity count stays 12). The scene's state hash changes (600 ticks 920e9e2e1157f8aa, 2700 ticks 4e5789623bb60c82, each identical on two runs of the built `mce_player`); `CloudLayer` leaves `sample_coverage.allow`.
