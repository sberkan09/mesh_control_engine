- Fix a stale water plane (WATERFIX): `Scene3D::begin` never cleared the water carrier and the kit extract only set it when an enabled `Water` existed, so after a `Water` was removed, disabled, given a non-finite level or its entity destroyed, the previous frame's plane (and the caustics and underwater look that follow it) kept drawing in the same `Scene3D`. `Kit3DExtract::extract` now resets the carrier to the disabled default every frame before the `Water` feed; a frame with an enabled `Water` is unchanged bit for bit.
