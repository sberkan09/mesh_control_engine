- Luau lightning bolt and the weather sample's `LightningBolt`, M-LIGHTNINGBOLT step 11d (milestone closed): `weather.bolt_min_range()`, `bolt_max_range()`, `bolt_ground_y()`, `bolt_height()`, `bolt_width()`, `bolt_segments()`, `bolt_jitter()`, `bolt_fork()`, `bolt_enabled()`, `bolt_light()` and `bolt_light_radius()` read the first `LightningBolt` (`mce/kit/lightning_bolt.h`) and `weather.set_bolt{min_range=, max_range=, ground_y=, height=, width=, segments=, jitter=, fork=, light=, light_radius=, enabled=}` writes it; `weather.bolt_distance()`, `weather.bolt_pos()` (returns `x, z`) and `weather.bolt_active()` read the last strike (engine-written, read-only). Every set key is optional and clamped to the component's Range (`segments` rounded down; `fork` and `enabled`: any non-zero number is 1); an unknown key (strike_x included), a non-number (NaN included) or a scene without the component (or a world without weather) raise a named Luau error and write nothing.
