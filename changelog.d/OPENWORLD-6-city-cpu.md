- Kit: big static cities cost less CPU per frame (M-OPENWORLD A3/A4). An unchanged `StaticMerge3D` group now costs a walk and a word-wise hash of its children's inputs; the mesh reads and material checks run only when that changes (24k children: 10 ms to 3 ms per frame), and `Kit3DStats::merged_rebuilt` counts the groups merged in a frame. The extract's per-entity arrays grow geometrically, so 24k entities appearing at once (an area streaming in) take 16 ms instead of 2.7 s.
