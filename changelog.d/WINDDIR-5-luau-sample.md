- Luau wind direction and the weather sample's turning wind, M-WINDDIR step 8e (milestone closed): `weather.wind_degrees()`, `weather.wind_drift()` and `weather.wind_heading()` read the first `WindDirection` (`mce/kit/wind_direction.h`; the heading is the engine-written `angle_q` in degrees, 0 up to 360) and `weather.set_wind_direction{degrees=, drift=}` writes the authored heading and drift. Every key is optional and values are clamped to the component's Range; an unknown key (the engine-written `angle_q`, `frac` and `seeded` included), a non-number (NaN included) or a scene without the component (or a world without weather) raise a named Luau error and write nothing. Typed in `mce.d.luau`. Sample `samples/12_weather`: the Weather entity carries a `WindDirection` (degrees 0, drift 6 degrees a minute) and the script logs `wind dir:` every 150 ticks (entity count stays 12). The scene's state hash changes (600 ticks 5463334e203a41ea, 2700 ticks bb09296188893bfb, each identical on two runs of the built `mce_player`); `WindDirection` leaves `sample_coverage.allow`.
