- Rain and snow particles follow the scene wind direction, M-WINDDIR step 8f: `kit_precipitation` leans the `Precipitation3D` emitter direction and gravity along the first `WindDirection`'s unit vector (`direction = (x*inv*u.x, -inv, x*inv*u.y)`, `gravity = (g*wind*u.x, -v, g*wind*u.y)`) instead of +x only, when a `Weather` and a `WindDirection` both exist; with no `WindDirection` the written bits equal the old formula (a test compares them). Tests in `tests/kit/test_precipitation_wind.cpp`. Sample `samples/12_weather` (it has a `WindDirection`, turning 6 degrees a minute) changes its state hash: 600 ticks 2844c6e99fa787cf (was 5463334e203a41ea), 2700 ticks 3eaf9918c1799c87 (was bb09296188893bfb), each identical on two runs of the built `mce_player`. No test pins these hashes. User guide 9.19d and 9.20.
