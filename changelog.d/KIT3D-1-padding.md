- Determinism: `Environment3D`, `Foliage3D`, `TerrainFoliage3D` and `ParticleEmitter3D` in `kit3d.h` had 4 bytes of compiler padding each that `World::state_hash` read; a component built as a local and set on an entity could give a flaky hash. They now carry explicit pad fields (sizes and offsets unchanged), and `tests/kit/test_padding.cpp` audits every `kit3d.h` component so a new hole fails the build's tests.
