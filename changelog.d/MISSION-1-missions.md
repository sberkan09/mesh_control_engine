- Missions and objectives, M-MISSION step 1: `Mission` and `Objective` (`mce/kit/missions.h`) build a chain of goals as data (reach a zone, kill, collect, interact, a named signal, a timer) with a time limit and `fail_on_death`, advanced by one tick-quantized system from `Died3D`, `TriggerEnter3D`, the Interact action and `MissionSignal` events. Events `MissionStarted`, `ObjectiveDone`, `MissionCompleted`, `MissionFailed`. State lives in components, so a save mid-mission resumes. Opt-in; user guide 9.13.
