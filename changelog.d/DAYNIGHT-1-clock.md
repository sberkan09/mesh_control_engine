- World clock, M-DAYNIGHT step 1: `WorldClock` (`mce/kit/world_clock.h`), one per scene, holds the hour of the day (`hour`, `day_length_seconds`, `time_scale`, `paused`, `day`) and one tick-quantized system advances it with no float drift (the hour after N ticks is an exact integer ratio) and writes `Environment3D.time_of_day` when `drive_environment` is set, so the sun moves without a script. Events `HourPassed` and `DayPassed`. State lives in components, so a save mid-day resumes. Opt-in; user guide 9.16.
